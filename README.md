# URL2QR

URL을 QR 코드로 만들고 QR 코드를 눌러 JPG로 다운로드하는 정적 웹 페이지입니다.

## 구현 계획

1. 로고와 URL 입력 화면을 정적 페이지로 구성합니다.
2. URL 검증 후 QR 코드를 생성하고 입력창을 아래로 이동합니다.
3. QR 이미지를 흰 여백을 포함한 JPG로 저장합니다.
4. 브라우저에서 정상 입력, 잘못된 입력, 다운로드, 모바일 배치를 확인합니다.

## 작업 목록

- [x] 제공된 `img/logo.png`를 화면 왼쪽 위에 배치
- [x] 중앙 URL 입력과 QR 생성, 생성 후 입력창을 아래로 이동
- [x] QR 코드 클릭 시 흰 여백이 있는 JPG 다운로드
- [x] 로고 색감과 어울리는 그라데이션, 커서 위치에 따라 변하는 색상
- [x] URL 오류 안내와 모바일·키보드 사용 대응

## 워크스루

`index.html`을 브라우저에서 열고 `https://example.com`을 입력한 다음 **QR 만들기**를 누릅니다. 가운데 나타난 QR 코드를 클릭하면 `url2qr.jpg`가 저장됩니다. 주소를 바꾸어 다시 만들 수도 있습니다. QR 생성 라이브러리와 웹 폰트는 인터넷 연결이 필요합니다.
